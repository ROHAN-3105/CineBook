# CineBook Frontend

React 18, TypeScript, Vite, Tailwind CSS, Axios and React Router UI on `http://localhost:5173`. It calls only the API Gateway, defaulting to `http://localhost:9090` via `VITE_API_BASE_URL` (`.env.example`). Requires the six backend modules for full use. Pages cover home, movies, movie details, showtimes, login, registration, booking, My Bookings, and ADMIN movie/showtime management. Login stores the raw JWT in localStorage for this local learning application; scripts on this origin can read it. Booking sends only showtime ID and seat quantity; the backend resolves user ownership. Movie posters use visual placeholders because the API has no poster field. From this directory run `npm install`, `npm run dev`; use `npm run build` for TypeScript and production output. From the root, start the backend with `.\start-all.ps1` first.
