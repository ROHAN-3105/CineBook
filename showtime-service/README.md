# Showtime Service

Spring Boot MVC/JPA and OpenFeign service for showtime data and seat inventory. It registers on a dynamic port. Requires MySQL `movie_ticketing`, Memurai/Redis at `localhost:6379`, Eureka, the shared Base64 `JWT_SECRET`, and Movie/Booking services for request-time Feign calls. `GET /api/showtimes` lists screenings; `GET /api/showtimes/{id}` includes the current user's booking details. ADMIN may POST `/api/showtimes/admin`. Redis reservation routes under `/api/showtimes/reservations` create, retrieve, confirm and cancel a quantity hold. Default hold duration is 300 seconds, configurable by `RESERVATION_DURATION_SECONDS`. Confirmation updates MySQL under a pessimistic row lock. The old direct seat-deduction route returns 410 Gone. From the root run `.\service.ps1 -Service showtime-service` (or `.\mvnw.cmd spring-boot:run` here with equivalent configuration). Test with `.\mvnw.cmd clean test`.
