# Booking Service

Spring Boot MVC/JPA and OpenFeign service for authenticated booking creation and owned history. It registers on a dynamic port. Requires MySQL `movie_ticketing`, Eureka, the shared Base64 `JWT_SECRET`, User Service for `/api/user/me`, and Showtime Service for Redis-backed reservation calls. `POST /api/bookings` accepts `showtimeId` and `seatsBooked`; the server resolves user ID from the validated token, creates and confirms a quantity hold, then saves the booking. `GET /api/bookings/mine` returns the caller's records. Existing `GET /api/bookings/{userId}` is owner-restricted. Cross-service failures after inventory confirmation require reconciliation; there is no distributed transaction. From the root run `.\service.ps1 -Service booking-service` (or `.\mvnw.cmd spring-boot:run` here with equivalent configuration). Test with `.\mvnw.cmd clean test`.
